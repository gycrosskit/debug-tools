# 版本记录

## 0.2.0-rc.4（预发布候选）

- 导航、编辑和操作开始同步清理 message/notice、错误和当前结果反馈，避免 CMP/Kuikly 读取不同字段时显示旧提示。保留草稿、历史和待核查 journal。
- 新增共同状态回归；Maven 九个 publication 完整归档校验通过。原生 HAR 未改，仍配套 rc.3，远程消费与设备状态见开发与验证记录。

## 0.2.0-rc.3（预发布）

- 初始恢复期间忽略凭据、草稿与开关操作，避免旧读取结果覆盖新状态。
- 鸿蒙原生桥验证 requestId/value 的真实类型与长度；存储键拒绝非字符串。
- 增加真实 Controller 延迟恢复与 ArkTS 生产源码参数回归。验证进度见[完整审查](完整审查.md)。

## 0.2.0-rc.1（预发布）

- 共用 BugReportController，Android/iOS 保留 BugReportViewModel；新增 OHOS/JVM 核心产物与独立 Kuikly 桥，OHOS 不引入 AndroidX。
- 新增鸿蒙 HAR：HUKS AES-256-GCM Token、私有草稿/队列、真实传感器注册结果及取消/销毁生命周期管理。
- 三端持久草稿和手动待提交恢复，稳定 reportId、目标绑定、UNKNOWN/CREATED 防重记录；不自动重放 HTTP 写入。
- 创建 Bug 后上传附件，保留已确认 File ID；失败可补传，结果未知先核查，不重复创建 Bug。
- typed notice、中英文默认文案与 Bug 正文标签；远端创建、本机存储、附件失败分别表达。
- 工具链对齐宿主 OHOS Kotlin/Ktor/coroutines/serialization 配套版本；九个 publication 本地检查。

远程发布与独立 Maven 消费已通过；真机、真实禅道写入与生产宿主接入另行验收，见 [开发与验证](开发与验证.md)。

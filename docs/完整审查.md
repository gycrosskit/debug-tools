# 0.2.0-rc.3 完整源码审查

范围为全部自有 Kotlin/ArkTS 生产实现及导出入口，共 22 个文件；逐文件 SHA 清单留在 `build/full-review/coverage.json`。覆盖 Controller/Repository、UNKNOWN 防重、附件、草稿、Token 存储、传感器和 Kuikly 回调生命周期；厂商 SDK 与生成代码不算自有实现。

## 修复

- Controller 的初始恢复与命令不能并发：loading 期间忽略操作，避免旧 Token/开关快照覆盖后来操作。恢复期间打开的表单在恢复后仍可采集证据；用户已离开则不采集。UI 沿用状态驱动，不增加排队或第二状态机。
- ArkTS native bridge 拒绝 null、错误类型、空/过长 requestId 及非字符串 write value；存储键不依赖 JS 正则的字符串强转。错误返回现有 error，不启动原生工作。

# 功能与平台差异

核对日期：2026-10-08。固定Git基线：`584f59be01d338c731d3a12a48a4975dc571ca36`。适用发布：Maven 0.2.0-rc.5；未变OHOS HAR继续0.2.0-rc.3。固定Git基线用于追溯发布前增量；最终不可变tag与渠道消费结果见对应GitHub Release。历史验收保留原版本，设备/业务未验收范围不因发布而改变。

组件提供 Bug 上报 Controller、草稿/队列/附件恢复、禅道 REST、安全 Token、摇动触发和页面轨迹；没有库内 CMP 或 KuiklyCompose 表单。五入口表表示对应宿主可消费平台 core/桥接能力，由宿主 UI 观察 `BugReportController.state` 并发起操作；不表示存在五个同名 Composable。品牌、准入、导航、证据脱敏和诊断采集由宿主负责。

## 公开功能与合同

- Controller公开编辑/导航、授权/连接测试、提交、草稿flush、pending人工恢复与附件补传；`state`中notice、working、pending、workspaceSaved、failedAttachments分别表达远程与本机结果，不能只读submittedUrl判断全部成功。
- `BugReportTarget` 与Context包含品牌、环境、版本、产品/branch/build和服务地址，均由宿主注入；Unavailable时不伪造可用目标。`BugEvidenceFormatter`只限长，不能代替脱敏。
- Repository先持久化READY/UNKNOWN，再调用创建；丢失回执必须人工核查/关联Bug ID后才能重试。启动/联网/授权不自动重发。pending队列最多10条未完成记录、最近20条完成回执用于防重；附件先有Bug ID再上传，不确定附件也需人工核查。
- 自定义 `BugReportStore` 仅实现Token/设置/历史；实现 `BugReportWorkspaceStore` 才有持久草稿/pending。`clearCredentials`只清Token，保留历史、草稿与设置。HTTP client使用专用生命周期，由owner关闭。
- Android Token用Keystore AES-GCM；iOS用Keychain、workspace用私有原子文件；OHOS HUKS AES-256-GCM配随机nonce。namespace/keyAlias等平台命名参数由宿主隔离品牌，不能共用同一存储名后声称隔离。
- 摇动start/stop由宿主准入与生命周期控制；2.7g、1200ms冷却、无replay，停用不重置冷却。iOS候选改用CoreMotion单调timestamp；页面轨迹有界且相邻去重。

## 差异分类与使用边界

| 分类 | 当前合同与限制 |
| --- | --- |
| 组件接口/产物边界 | 没有库内表单UI；`debug-tools-kuikly`只发OHOS target，Android/iOS Kuikly消费根模块平台core，不能照搬OHOS桥坐标。 |
| OS/SDK边界 | Android Keystore、iOS Keychain/私有文件、OHOS HUKS/偏好为不同实现；iOS真实正常增改查删已验，系统锁屏/异常注入与Android/OHOS失效恢复尚未验。 |
| 宿主输入 | 产品/branch/build、品牌地址、token、namespace、证据/附件读取与脱敏、授权和摇动生命周期由宿主决定。 |
| 未验收 | 真实传感器摇动、Keystore/HUKS失败环境、真实禅道创建/附件业务及宿主表单可用性未本轮验收。禁止把MockEngine成功当真实Bug创建。 |
